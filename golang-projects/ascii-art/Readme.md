# 🎨 ASCII Art Generator

[![Go Version](https://img.shields.io/badge/Go-1.18%2B-blue.svg)](https://golang.org/)

Проект на языке **Go**, который превращает обычные строки текста в стилизованные графические ASCII-представления. Программа считывает шаблоны из файлов-баннеров и отрисовывает каждый символ послойно.

---

## 🚀 Как это работает

В основе программы лежит алгоритм сопоставления десятичного кода символа (ASCII) с его графическим представлением в текстовом файле.

### 🧮 Математическая логика
Для поиска индекса строки каждого символа используется следующая формула:

> **`LineIndex = (ASCII_Value - 32) * 9 + LineNumber`**

**Разбор параметров:**
* **`ASCII_Value`**: Десятичный код символа (например, для пробела — `32`).
* **`- 32`**: Смещение. Файлы баннеров начинаются с пробела (код 32), поэтому мы вычитаем 32, чтобы получить индекс `0` для первого доступного символа.
* **`* 9`**: Каждый символ в шаблоне занимает **9 строк** (8 строк самой буквы + 1 пустая строка-разделитель).
* **`LineNumber`**: Текущая строка отрисовки (от 1 до 8), так как вывод в консоль происходит построчно для всей фразы сразу.

## ✨ Особенности

* 📦 **Поддержка нескольких шрифтов**: В комплекте идут `standard.txt`, `shadow.txt` и `thinkertoy.txt`.
* 🔡 **Полный охват**: Обработка цифр, латиницы, пробелов и специальных символов.
* ↵ **Управление строками**: Корректная обработка управляющей последовательности `\n`.
* 🎯 **Точность**: Строгое соблюдение высоты символов в 8 строк и корректное горизонтальное выравнивание.

## 💻 Запуск программы

Используйте команду `go run .`, передав текст аргументом. Вы также можете указать название шрифта вторым аргументом.

### Базовое использование
```bash
# Обычный вывод
go run . "Hello World"

# Шрифт Shadow
go run . "Hello" shadow

# Шрифт Thinkertoy
go run . "ASCII" thinkertoy
```

## ⚠️ Устранение неполадок

Ошибки отображения (символы ^M или съехавшие строки)
Если вы запускаете проект на Linux или macOS, а файлы баннеров были созданы в Windows, возникнет конфликт окончаний строк (CRLF vs LF).

Решение: используйте утилиту dos2unix для конвертации файлов в нужный формат:
```bash
dos2unix shadow.txt standard.txt thinkertoy.txt
```
