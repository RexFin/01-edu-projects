# Tetris-Optimizer

**Tetris-Optimizer** - это консольная программа на языке Go, предназначенная для поиска минимального возможного квадрата, в который можно уместить заданный набор тетромино (фигур из 4 блоков). Программа читает фигуры из файла, использует рекурсивный алгоритм бэктрекинга (поиска с возвратом) для их идеальной расстановки и выводит готовый результат в консоль.

---

## Основные возможности

### 1. Умный алгоритм упаковки (Backtracking)
* Программа математически вычисляет минимально возможный размер доски для старта (например, для 4 фигур это квадрат 4x4).

* Если фигуры физически не помещаются из-за своей формы, алгоритм автоматически увеличивает размер доски (например, до 5x5) и повторяет попытку, гарантируя нахождение самого плотного решения.

* Каждая фигура на итоговой доске помечается уникальной заглавной буквой по алфавиту (первая — `A`, вторая — `B` и т.д.).

### 2. Модуль аналитики (Флаг `--analyze`)
При запуске с флагом `--analyze` программа не только собирает квадрат, но и выдает подробную сводку:

* Качество решения: Итоговый размер доски, количество заполненных и пустых клеток, процент компактности и сравнение с теоретическим минимумом.

* Производительность: Время выполнения алгоритма, количество попыток примерить фигуру (Placement attempts) и количество откатов алгоритма при попадании в тупик (Backtracks).

### 3. Режим визуализации (Bonus Visualizer)
Дополнительная точка входа, которая превращает процесс решения в анимацию.

* Выводит в консоль каждый шаг алгоритма в реальном времени.

* Позволяет наблюдать, как программа ставит фигуры, заходит в тупик, стирает ходы и пробует новые комбинации.

### 4. Строгая валидация формата
Встроенный парсер проверяет входные файлы на соответствие правилам: ровно 4 блока на фигуру, сетка 4x4, допустимые символы (`#` и `.`), наличие пустых строк между фигурами. Любое нарушение безопасно прерывает программу с сообщением `ERROR`.

## 🛠 Установка

Для работы потребуется установленный [Go](https://go.dev/dl/) (версии 1.27 или выше).

1. Клонируйте репозиторий:
```bash
git clone https://01.tomorrow-school.ai/git/nkishiba/tetris-fit
```

2. Перейдите в директорию проекта:
```bash
cd tetris-fit
```

## Использование

В проекте есть две точки входа: основной оптимизатор и бонусный визуализатор. В качестве аргумента передается путь к текстовому файлу с фигурами.

### Запуск тестов:
```go
go test ./...
```

### Стандартный запуск:
```go
go run cmd/tetris-optimizer/main.go testdata/goodexample00.txt
```

### Запуск с аналитикой:
```go
go run cmd/tetris-optimizer/main.go testdata/goodexample01.txt --analyze
```
Примерный результат аналитики:
```bash
[Solution output]

=== Solution Analysis ===

Input file: testdata/goodexample01.txt
Tetrominoes: 4

Solution quality:
  Grid size: 5x5 (25 cells)
  Filled cells: 16
  Empty cells: 9
  Compactness: 64.00%
  Theoretical minimum: 4x4 (differ)

Performance:
  Execution time: 0ms
  Placement attempts: 44
  Backtracks: 40
```

### Запуск визуализатора (Анимация процесса):
```bash
go run cmd/tetris-visualizer/main.go testdata/goodexample03.txt
```
