# Tour Track

> **Tour Track** - веб-приложение на Go для просмотра артистов и анализа их гастрольной активности. Оно получает каталог из Groupie Trackers API, объединяет сведения об исполнителях, датах, локациях и связях между ними, а затем отображает карточки артистов с оценкой активности.

---

## Возможности

| Функция | Описание работы |
| :--- | :--- |
| **Каталог артистов** | Отображает всех исполнителей, полученных от API. Главная страница автоматически сортирует карточки по имени. |
| **Фильтр по годам** | Позволяет искать артистов по году начала деятельности с указанием нижней, верхней или обеих границ. |
| **Карточка артиста** | Отдельная страница с участниками группы, датой первого альбома, числом концертов, количеством стран и расписанием туров. |
| **Оценка активности** | Присваивает значок уровня популярности и дополнительный бейдж `Rising Star`, если гастрольная активность ускорилась. |
| **Демо-режим** | Показывает локальный каталог с предупреждением, если основной запрос к внешнему API временно не удался. |

## Требования и запуск

| Параметр | Значение |
| :--- | :--- |
| **Версия Go** | `Go 1.25` или новее (используется только стандартная библиотека). |
| **Сеть** | Доступ к интернету для актуальных данных API (при отсутствии сети включается локальный набор). |
| **Команда запуска** | `go run .` (выполняется из корневой папки проекта). |
| **Адрес в браузере** | [http://localhost:8080](http://localhost:8080) (остановка сервера - `Ctrl+C` в терминале). |

> **Встроенные ресурсы:** HTML-шаблоны и файлы из `static/` встраиваются в бинарный файл приложения. Стили находятся в `static/css/site.css`, локальная SVG-заглушка - в `static/images/artist-placeholder.svg`, а изображения артистов - в `static/images/artists/`.

## Источник данных

Клиент API настроен на базовый адрес `https://01edu.ai` и связывает данные по ID артиста:

| Эндпоинт | Назначение и формат данных |
| :--- | :--- |
| **`/artists`** | Основной состав каталога. Поддерживает ответ в виде JSON-массива, а также обёртки с полем `value` или `index`. |
| **`/locations`** | Справочник городов и стран проведения концертов. |
| **`/dates`** | Список дат прошедших и запланированных выступлений. |
| **`/relation`** | Таблица связей между артистами, датами и конкретными локациями. |

### Отказоустойчивость

| Сценарий сбоя | Поведение приложения |
| :--- | :--- |
| **Недоступны доп. ресурсы** | Если `/artists` ответил успешно, а `/dates`, `/locations` или `/relation` недоступны, каталог отобразится с неполной статистикой. |
| **Недоступен `/artists`** | Включается локальный набор: *Queen*, *Gorillaz*, *Foo Fighters* и *Travis Scott* (данные для последних трёх берутся из `repository/preview_dates.json` и `repository/preview_locations.json`). |

## Оценка активности

Пакет `internal/activity` рассчитывает итоговый балл каждого артиста по формуле:

```text
score = (число уникальных стран × 2) + (число дат концертов × 3) + min(10, лет карьеры / 5)
```

| Правило расчёта | Пояснение |
| :--- | :--- |
| **Продолжительность карьеры** | Текущий год минус год начала деятельности. Деление целочисленное: `+1` балл за каждые полные 5 лет (максимум `10` баллов). |
| **Отрицательные значения** | Отрицательные показатели стран, концертов и стажа при расчёте автоматически заменяются на `0`. |
| **Извлечение страны** | Берётся из последней части названия локации API (например, `country` из строки `city-country`). |
| **Подсчёт концертов** | Считается по общему списку дат выступлений конкретного артиста. |

### Уровни активности и Rising Star

| Диапазон баллов | Уровень | Условие значка `Rising Star` |
| :---: | :--- | :--- |
| **`0-10`** | **Emerging** | Среднее число концертов в год за **последние 2 года** строго больше **150%** от среднего за всю карьеру. |
| **`11-25`** | **Active** | При нулевом или отрицательном стаже значок `Rising Star` не присваивается. |
| **`26-40`** | **Established** | Перед разбором дат автоматически удаляется служебный префикс `*`, если он присутствует в ответе API. |
| **`41+`** | **Legendary** | Статус присваивается автоматически при достижении 41 балла и выше. |

## Структура проекта

| Путь | Описание содержимого |
| :--- | :--- |
| **`go.mod`** | Описание модуля и минимальная требуемая версия Go. |
| **`main.go`** | Точка входа, запуск HTTP-сервера и встраивание статических ресурсов (`embed`). |
| **`http/`** | Обработчики маршрутов главной страницы и персональных страниц артистов. |
| **`repository/`** | Клиент внешнего API, модели данных и встроенные демонстрационные снимки. |
| **`internal/activity/`** | Логика расчёта баллов, классификация уровней и детектор `Rising Star`. |
| **`templates/`** | HTML-шаблоны пользовательского интерфейса. |
| **`static/`** | CSS-стили, SVG-заглушка и локальные изображения артистов. |

## Тестирование

Запустите модульные и интеграционные тесты всех пакетов из корневой директории:

```sh
go test ./...
```

| Пакет тестов | Что проверяет |
| :--- | :--- |
| **`internal/activity`** | Корректность расчёта по формуле, граничные значения уровней и срабатывание `Rising Star`. |
| **`repository`** | Чтение, парсинг и объединение данных из разных эндпоинтов API. |
| **`http`** | Коды ответов HTTP-сервера, рендеринг страниц и переключение в демонстрационный режим. |
